# 🎵 FeminXDlol

Минималистичный веб-клиент для прослушивания музыки, построенный вокруг низкоконтрастной темной палитры (**Matte Obsidian & Smoked Glass**) и островной архитектуры интерфейса в духе современных десктопных ОС.

> **Статус проекта:** 🚧 В активной разработке (UI / Frontend stage).
> В данный момент репозиторий содержит клиентскую часть интерфейса. В отдельной ветке ведется разработка собственного бэкенда и облачного хранилища аудиофайлов для превращения клиента в полноценный стриминговый сервис.

## ✨ Особенности дизайна и UI
* **Low-Contrast Tonal Layering:** Мягкое разделение слоев интерфейса без визуального шума, резких рамок и неонового свечения.
* **Floating Architecture:** Парящий сайдбар и компактная стеклянная капсула плеера (`backdrop-filter`).
* **Dynamic Cover Accent:** Единственный акцентный цвет интерфейса и фоновая ambient-подложка динамически подстраиваются под средний оттенок обложки текущего трека.
* **Editorial & Tech Typography:** Сочетание журнальной антиквы для заголовков и моноширинного шрифта (`tabular-nums`) для таймкодов и метаданных.
